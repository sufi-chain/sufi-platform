# Roadmap

This page is the public place to describe what is planned next for the open-source Sufi Platform base.

## Purpose

Use this page to communicate planned work at a product level without mixing roadmap assumptions into technical documentation pages.

Product owners can use this page to express needs in a way that is useful for maintainers and delivery teams: describe the user problem, the expected outcome, the affected modules, and the priority.

## Suggested structure

When you are ready to publish roadmap content, organize it like this:

### Near term

- modules or features targeted next
- platform capabilities being finalized
- documentation areas being completed

### Mid term

- larger module additions
- stronger integration scenarios
- tooling and template improvements

### Long term

- broader platform capabilities
- ecosystem growth
- product-level expansion areas

## Notes

- Keep roadmap items product-oriented and easy for product owners and technical teams to understand.
- Link roadmap items to canonical docs pages once the feature or module becomes part of the public source.
- Do not use this page to document implementation details that belong in module or framework docs.
- Keep roadmap language focused on the LGPL open-source base and avoid private distribution details.
