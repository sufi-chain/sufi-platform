# File Manager Features

Use this page to map file and media requirements to the parts of File Manager you can reuse before building a product-specific upload or asset workflow.

## Core capabilities

- single and multiple file uploads
- file structures for validation and business-specific upload rules
- folder hierarchy and browsing
- thumbnails and image and video processing
- rich text editor file and image integration
- public file presentation components
- entity-linked file organization
- storage configuration and quota-oriented settings

## UI capabilities

### Administrative UI

The admin Blazor package includes pages for:

- `AssetManager`
- `FileStats`
- `FileStructures`

### Public UI

The public Blazor package includes reusable components such as:

- attachment list
- download link
- gallery
- image display
- video display

### Demo coverage

The demo project includes pages for:

- file manager overview
- upload flows
- file browser
- asset manager
- file structures
- rich text editor integration

## Platform role

This module gives teams a shared asset platform instead of custom per-module upload implementations. It is especially valuable for applications that need reusable document, image, and media handling across many business modules.
