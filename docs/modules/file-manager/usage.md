# File Manager Usage

## Typical scenarios

- attach files to business entities
- upload and manage media in administrative screens
- browse folders and assets in an asset manager
- define file structures for different business use cases
- render public galleries, images, videos, and download links
- embed image and file selection in rich-text-editing experiences

## Common application patterns

### Business-entity attachments

Use the module when a business entity needs one or more linked files, such as:

- profile images
- product galleries
- attachments
- marketing assets
- content-related files

### Administrative media management

Use the administrative pages when operators need a reusable media-management experience instead of per-screen upload widgets.

### Public asset presentation

Use the public Blazor package when files must be rendered or downloaded in end-user experiences.
