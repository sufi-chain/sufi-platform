# Editions Permissions

| Permission | Purpose |
|------------|---------|
| `SufiEditions.Editions` | Default editions access |
| `SufiEditions.Editions.Create` | Create editions |
| `SufiEditions.Editions.Update` | Update editions |
| `SufiEditions.Editions.Delete` | Delete editions |
| `SufiEditions.Editions.ManageFeatures` | Bind feature policy values |

Confirm exact permission names in `SufiChain.SufiPlatform.Editions.Domain.Shared` if they differ after localization updates.
