# Identity Permissions

The module adds or documents these permission areas:

| Permission | Purpose |
| --- | --- |
| `AbpIdentity.SecurityLogs` | View security log functionality |
| `AbpIdentity.OrganizationUnits` | Access organization-unit management |
| `AbpIdentity.OrganizationUnits.Create` | Create organization units |
| `AbpIdentity.OrganizationUnits.Update` | Update organization units |
| `AbpIdentity.OrganizationUnits.Delete` | Delete organization units |
| `AbpIdentity.OrganizationUnits.ManageMembers` | Manage organization-unit membership |
| `AbpIdentity.OrganizationUnits.ManageRoles` | Manage organization-unit roles |
