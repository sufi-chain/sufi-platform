# Identity Usage

## Typical administrative workflows

- create and edit users
- manage roles
- create and maintain organization units
- add and remove organization-unit members
- add and remove organization-unit roles
- inspect security logs

## UI pages in source

The Blazor package contains pages for:

- `UserManagement`
- `RoleManagement`
- `OrganizationUnitManagement`
- `SecurityLogManagement`

## Public value

Identity is one of the main modules that product owners and administrators rely on immediately in most business applications, since it provides the core people and access-management experience.
