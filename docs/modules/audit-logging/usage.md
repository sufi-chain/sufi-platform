# Audit Logging Usage

## Typical operator workflows

- open the audit logs page
- filter and inspect request activity
- review action details for a request
- inspect entity changes when available
- investigate exceptions and execution context

## UI and DTO highlights in source

The public source includes:

- `AuditLogs` page
- DTOs for audit-log and entity-change list/detail behavior

## Why it matters

Audit Logging is one of the most important operational modules for support, troubleshooting, compliance, and security review workflows.
