# Feature Management Features

Use this page to map feature-driven product behavior to the contracts, APIs, and administration UI that already exist in the platform.

## Core capabilities

- wrap ABP feature-management contracts and services in Sufi packages
- expose feature-management behavior through HTTP APIs
- support administrative feature-management workflows
- participate in tenant-oriented feature scenarios

## Source highlights

The module includes an HTTP API controller named `FeaturesController`, indicating a defined remote surface for reading and updating feature-related behavior.

## Platform role

Feature Management helps teams control configurable application behavior without creating custom switches or hard-coded product toggles in every application.
