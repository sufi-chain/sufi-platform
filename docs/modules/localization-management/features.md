# Localization Management Features

Use this page to map translation and localization-management requirements to the pages and persistence layers that already exist in the platform.

## Core capabilities

- resource management
- text creation, update, and deletion
- text import and export
- localization caching support
- external-store integration patterns
- EF Core and MongoDB persistence options

## UI capabilities in source

The Blazor package contains pages for:

- `LocalizationResources`
- `LocalizationTexts`

## Platform role

Localization Management gives teams a reusable way to manage translation assets and runtime localization content without building custom translation administration tooling.
