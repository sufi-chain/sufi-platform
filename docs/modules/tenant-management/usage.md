# Tenant Management Usage

## Typical host-administrator workflows

- browse tenants
- create and update tenant records
- switch to tenant-oriented operational tasks
- review tenant-specific settings and feature-related behavior
- use tenant-lookup and tenant-selector experiences where needed

## UI and service highlights

The public source includes:

- `TenantManagement` page for administrative operations
- tenant-related menu integration
- anonymous tenant lookup contracts and services for selector-style experiences

## Why it matters

Tenant management is central to SaaS-style and multi-organization applications built on Sufi Platform.
