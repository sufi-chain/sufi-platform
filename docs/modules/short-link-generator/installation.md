# Short Link Generator Installation

See also the main module hub page: [Index](index.md).

The module typically requires:

- `SufiShortLinksApplicationModule`
- one persistence module: `SufiShortLinksEntityFrameworkCoreModule` or `SufiShortLinksMongoDbModule`
- `SufiShortLinksHttpApiModule`
- `SufiShortLinksBlazorModule` and `SufiShortLinksHttpApiClientModule` for Blazor hosts
