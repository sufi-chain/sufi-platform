# Short Link Generator Installation

See also the main module hub page: [Index](index.md).

The module typically requires:

- `SufiAbpShortLinkGeneratorApplicationModule`
- one persistence module: `SufiAbpShortLinkGeneratorEntityFrameworkCoreModule` or `SufiAbpShortLinkGeneratorMongoDbModule`
- `SufiAbpShortLinkGeneratorHttpApiModule`
- `SufiAbpShortLinkGeneratorBlazorModule` and `SufiAbpShortLinkGeneratorHttpApiClientModule` for Blazor hosts
