# Short Link Generator Usage

## Typical scenarios

- generate short links for long application URLs
- create expiring links for time-sensitive workflows
- use public short codes for redirect flows
- review click activity for operational or marketing visibility

## Typical administrator workflow

- open the short-link management page
- create or edit a short link
- copy the generated URL
- review activity and analytics
- deactivate or delete links when they are no longer needed
