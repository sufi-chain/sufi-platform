# Background Jobs Features

Use this page to map operational job-management requirements to the screens and APIs that already exist in the platform.

## Core capabilities

- background-job administration page
- job listing and filtering support
- retry behavior for relevant jobs
- delete behavior for stale or unwanted jobs
- permission-based operational access

## UI and API highlights in source

The public source includes:

- `BackgroundJobsManagement` page
- `BackgroundJobController`
- DTOs for job listing and job details

## Platform role

This module gives operations teams a reusable platform surface for background-job monitoring and action.
