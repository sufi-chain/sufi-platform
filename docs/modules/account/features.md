# Account Features

Use this page to map the Account module's visible behavior to the pages, contracts, and APIs you will touch when extending authentication flows in a host application.

- login flow

The source includes HTTP API controllers for:

- account-related operations
- profile-related operations

## Platform role

The Account module provides the end-user-facing access and self-service experience that complements the administrative capabilities of the Identity module.
