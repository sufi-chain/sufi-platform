# Account Installation

## Typical usage

Use this module when the application needs user-facing account pages and supporting API integration.

## Main packages

- `SufiChain.SufiPlatform.Account.Application.Contracts`
- `SufiChain.SufiPlatform.Account.Application`
- `SufiChain.SufiPlatform.Account.HttpApi`
- `SufiChain.SufiPlatform.Account.HttpApi.Client`
- `SufiChain.SufiPlatform.Account.Blazor`

## Notes

This module follows the standard ABP layering used in Sufi Platform and is intended to be integrated into hosts that already use the platform's UI and authentication model.
