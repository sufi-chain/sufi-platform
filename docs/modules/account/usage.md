# Account Usage

## Typical user journeys

- an unauthenticated user opens the login page
- a new user opens the registration page
- an authenticated user reviews profile information
- an authenticated user changes password

## UI pages in source

The Blazor package contains pages for:

- `Login`
- `Register`
- `Profile`
- `ChangePassword`

## Why it matters

This module gives applications a reusable account experience rather than requiring each project to design its own entry and self-service flows.
